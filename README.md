# Leoverse Contacts 📇

Leoverse Contacts aik modern, iOS-style web application hai jis ki madad se aap apni **VCF** aur **CSV** contact files ko aasani se manage, merge, aur export kar sakte hain.

## 🚀 Features (Khususiyaat)

* **Easy Import:** Apni VCF aur CSV files ko aik click mein website par load karein.
* **Modern iOS UI:** Apple ki design guidelines ke mutabiq saaf-suthra aur khoobsurat card-style interface.
* **Duplicate Merging:** Automatic tareeqay se duplicate numbers aur contacts ko merge karta hai taake list saaf rahe.
* **Instant Search:** Search bar ki madad se kisi bhi contact ko foran talash karein.
* **Batch Export:** Multiple ya sabhi contacts ko select kar ke dobara **VCF format** mein export karein.

\---

## 📖 Yeh Website Kaise Kaam Karti Hai? (User Guide)

Aap is website ko istemal karne ke liye in simple steps ko follow kar sakte hain:

1. **Contacts Import Karein:**

   * Screen ke top par bane hue **"Import VCF/CSV"** button par click karein.
   * Apne computer ya mobile se apni contact file(s) select karein.
   * File load hote hi aap ke sabhi contacts modern cards ki shakal mein screen par nazar aane lagenge.
2. **Contacts Talash (Search) Karein:**

   * Agar aap ko koi khaas contact chahiye, toh uper diye gaye **"Search contacts..."** bar mein uska naam ya number type karein. List khud-ba-khud filter ho jaye gi.
3. **Contacts Select Karein:**

   * Kisi bhi contact card par click kar ke aap use select kar sakte hain.
   * Agar aap sabhi contacts ko aik sath select karna chahte hain, toh uper diye gaye **"Select All"** button par click karein.
4. **Contacts Export Karein:**

   * Apni marzi ke ya sabhi contacts select karne ke baad uper **"Export Selected"** button par click karein.
   * Aap ke select kiye gaye contacts ki nayi `.vcf` file foran aap ke system mein download ho jaye gi.
